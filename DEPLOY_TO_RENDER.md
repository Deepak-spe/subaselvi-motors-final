## Troubleshooting:

**If deployment fails:**
- Check that render.yaml is in your repository
- Ensure your GitHub repository is public
- Verify your Render account has the free plan active

**If data not saving:**
- Check that persistent disk is mounted (configured in render.yaml)
- Verify the data directory has write permissions
- Check Render logs for any errors
